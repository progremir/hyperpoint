# Ratchet — logo guidelines

**Idea:** Ratchet → rat → mouse. A menu-bar app for your mouse, named after one. The symbol is a rat's face built from
one long wedge, two ears and two eyes. The long snout and small ears keep it a rat, not a cartoon mouse.

`ratchet-kit-overview.png` shows everything on one page. `presentation.html` is the board with mockups (README,
terminal, website, app icon, browser tab, sticker).

## 1. Files

| Need | File |
|---|---|
| Symbol, full colour (light backgrounds) | `svg/ratchet-symbol-color.svg` |
| Symbol on ink / dark backgrounds | `svg/ratchet-symbol-color-on-dark.svg` |
| One colour | `svg/ratchet-symbol-black.svg` · `-white.svg` · `-pink.svg` |
| Small sizes (under 40 px) | `svg/ratchet-symbol-small.svg` |
| Horizontal lockup (primary) | `svg/ratchet-horizontal-{color,color-on-dark,black,white}.svg` |
| Stacked lockup | `svg/ratchet-stacked-{…}.svg` |
| Wordmark only | `svg/ratchet-wordmark-{…}.svg` |
| macOS app icon | `macos/AppIcon.icns` (from `svg/ratchet-app-icon.svg`, Apple's 824/1024 grid) |
| Menu-bar icon | `macos/MenuBarTemplate.png` + `@2x`, or `macos/ratchet-menubar-template.svg` |
| Web | `web/` — favicon.ico/svg, PNG icons, `site.webmanifest`, `head-snippet.html` |
| PNG masters | `png/` (1024 px symbols, 1200 px lockups, transparent) |

Everything is generated by `build.py` (geometry, wordmark, lockups) and `overview.py`. Change the geometry there and
re-run; don't edit the SVGs by hand.

**Menu bar:** load the template and set `image.isTemplate = true` so macOS tints it for light and dark menu bars and
for the highlighted state. It is the small cut, black on transparent, 18 × 18 pt.

## 2. Construction

256-unit grid. Snout: a wedge from a flat brow (y 86) to a round tip (r 26). Ears: r 30 discs, cut away from the face by
a 10-unit gap (14 in the small cut). Eyes: r 11 holes (r 15 in the small cut). All of it is one evenodd path plus the ear
discs: there are no strokes, masks or white shapes painted on top, so every colour variant is a plain recolour.

## 3. Clear space and minimum size

Clear space on every side = **one ear diameter** (60 units at the 256 master, about a quarter of the symbol's height).

| Version | Minimum |
|---|---|
| Symbol | 16 px, using the small cut below 40 px |
| Horizontal lockup | 96 px wide |
| Stacked lockup | 64 px wide |

## 4. Colour

| Name | HEX | RGB | Use |
|---|---|---|---|
| Ink | `#18181D` | 24 24 29 | Face, wordmark, app-icon tile |
| Rat Pink | `#FF6F96` | 255 111 150 | The ears. Accent on Ink (6.7:1). Never as text on white (2.6:1) |
| Deep Pink | `#D93A6A` | 217 58 106 | One-colour pink logo on white (4.4:1) |
| Paper | `#FFFFFF` | 255 255 255 | Face on dark, backgrounds |

Print values (approximate, check against a swatch book before printing): Ink ≈ C0 M0 Y0 K92 or Pantone Black 6 C;
Rat Pink ≈ Pantone 1777 C; Deep Pink ≈ Pantone 7424 C.

**Approved pairs:** colour on white · colour-on-dark on Ink or any dark background · black on light · white on dark ·
deep pink on white. Pink stays on the ears only; the face is never pink in the full-colour version.

## 5. Typography

Wordmark: **Inter Display SemiBold**, converted to outlines, tracked −12/1000 em with hand kerning (`Ra`, `at`, `tc`, `et`).
Inter is SIL Open Font License, so logo use is fine. For UI and docs use the system font (SF Pro) or Inter.

## 6. Don'ts

Don't stretch, rotate or tilt the rat · don't make the ears bigger (that's the road to Mickey) · don't colour the
face pink · don't add outlines, shadows or gradients · don't close the ear gaps · don't retype the wordmark, use the files ·
don't use the full-size cut below 40 px.

## 7. Open items

- No trademark or App Store search has been run for "Ratchet". Do one before renaming the app.
- The wordmark is stock Inter with custom spacing. Custom-drawing one letter (the `R` or the `t`s) would make it more ownable.
- The app still uses `cursorarrow.rays` and the Hyperpoint name. Wiring in `AppIcon.icns` and the menu-bar template is a separate change.
