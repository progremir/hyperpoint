# Hyperpoint — logo guidelines

**Idea:** The Caps Lock glyph ⇪ tipped over 22 degrees until it becomes a pointer. Caps Lock is the key Hyperpoint turns into hyper, and the pointer is what the app drives. The bar under the arrow is the key's lit LED and carries the green.

`hyperpoint-logo-overview.png` shows everything on one page. `presentation.html` is the board with mockups (README,
terminal, website, app icon, browser tab, sticker).

## 1. Files

| Need | File |
|---|---|
| Symbol, full colour (light backgrounds) | `svg/hyperpoint-symbol-color.svg` |
| Symbol on ink / dark backgrounds | `svg/hyperpoint-symbol-color-on-dark.svg` |
| One colour | `svg/hyperpoint-symbol-black.svg` · `-white.svg` · `-green.svg` |
| Small sizes (under 40 px) | `svg/hyperpoint-symbol-small.svg` |
| Horizontal lockup (primary) | `svg/hyperpoint-horizontal-{color,color-on-dark,black,white}.svg` |
| Stacked lockup | `svg/hyperpoint-stacked-{…}.svg` |
| Wordmark only | `svg/hyperpoint-wordmark-{…}.svg` |
| macOS app icon | `macos/AppIcon.icns` (from `svg/hyperpoint-app-icon.svg`, Apple's 824/1024 grid) |
| Menu-bar icon | `macos/MenuBarTemplate.png` + `@2x`, or `macos/hyperpoint-menubar-template.svg` |
| Web | `web/`: favicon.ico/svg, PNG icons, `site.webmanifest`, `head-snippet.html` |
| PNG masters | `png/` (1024 px symbols, 1200 px lockups, transparent) |

Everything is generated by `build.py` (geometry) through `kitlib.py` (variants, lockups, icons, overview).
Change the geometry there and re-run `python3 design/logo/build.py`; don't edit the SVGs by hand. It needs
`rsvg-convert` (`brew install librsvg`), `fonttools` (`pip3 install --user fonttools`) and Inter (`brew install --cask font-inter`).

**Menu bar:** load the template and set `image.isTemplate = true`, so macOS tints it for light and dark menu bars and
for the highlighted state. It is the small cut, black on transparent, 18 × 18 pt. The current app uses
`NSImage(systemSymbolName: "cursorarrow.rays")` in `Sources/Hyperpoint/StatusMenu.swift`.

## 2. Construction

Arrow outline: the symmetric ⇪ polygon (tip 128,30; wings at y 118; stem 92–164 down to y 156), stroked 22 units wide with round joins and expanded to one evenodd path. Bar: 96 × 26, r 8, 26 units below the stem. The whole glyph is rotated −22° about (128,136). Small cut: 30-unit stroke, 100 × 32 bar. There are no strokes, masks or white shapes painted on top in the files, so every colour version is a
plain recolour.

## 3. Clear space and minimum size

Clear space on every side = **the bar's length** (about a third of the symbol's width).

| Version | Minimum |
|---|---|
| Symbol | 16 px, using the small cut below 40 px |
| Horizontal lockup | 120 px wide |
| Stacked lockup | 72 px wide |

## 4. Colour

| Name | HEX | RGB | Use |
|---|---|---|---|
| Ink | `#18181D` | 24 24 29 | Glyph, wordmark, app-icon tile |
| Caps Green | `#52E07A` | 82 224 122 | The bar only. Accent on Ink (10.4:1). Never on white (1.7:1) |
| Deep Green | `#138A48` | 19 138 72 | One-colour green logo on white (4.4:1) |
| Paper | `#FFFFFF` | 255 255 255 | Glyph on dark, backgrounds |

Print values (approximate, check against a swatch book before printing): Ink ≈ C0 M0 Y0 K92 or Pantone Black 6 C;
Caps Green ≈ Pantone 7479 C; Deep Green ≈ Pantone 7740 C.

**Approved pairs:** colour on white · colour-on-dark on Ink or any dark background · black on light · white on dark ·
deep green on white. Green stays on the bar; the arrow is never green in the full-colour version.

## 5. Typography

Wordmark: **Inter Display SemiBold**, converted to outlines, tracked −12/1000 em with hand kerning (`Hy`, `yp`, `rp`).
Inter is SIL Open Font License, so logo use is fine. For UI and docs use the system font (SF Pro) or Inter.

## 6. Don'ts

Don't stretch, rotate or re-tilt the glyph · don't fill the arrow in · don't move the bar or change its colour to
anything but Caps Green or the one-colour version · don't add outlines, shadows or gradients · don't retype the
wordmark, use the files · don't use the full-size cut below 40 px.

## 7. Open items

- The tilt costs clarity: below 24 px the arrow blurs into a squiggle. The small cut helps, but the menu-bar icon
  is the weakest use of this mark. Check it in the real menu bar before shipping.
- The −22° rotation leaves the edges off the 0/15/30/45° grid. That's deliberate; don't snap them.
- No trademark or App Store search has been run for "Hyperpoint".
- The wordmark is stock Inter with custom spacing. Custom-drawing one letter would make it more ownable.
