Why it exists

Two apps for one desk, and a mouse that forgets

Before

  • BetterMouse for the buttons and the wheel, Karabiner for the hyper key. Two apps, two settings, two sets of permissions.
  • The MX Master 3 drops its button setup when it sleeps or reconnects, which can happen many times a day.
  • A typo in a settings file can quietly turn a rule off, and nothing tells you.

With Hyperpoint

  • One menu bar app and one file, ~/.config/hyperpoint/config.json, for every mouse and keyboard you use.
  • On every connect Hyperpoint writes the whole setup back to the device, and the menu shows when it did.
  • A file with a mistake is rejected whole, with the path of the error, and the last good settings keep running.

A hyper key on Caps Lock

Hold Caps Lock and every key you press gets Control, Option, Shift and Command, ready for app shortcuts. Pick the keyboards it works on, or switch it off everywhere from the menu bar.

A wheel that glides

Change a button by pressing it

Click Add Rule and press the button, key or thumb wheel. Hyperpoint makes the rule for that control, then you pick what it does: Mission Control, App Exposé, a Space, any shortcut or a held modifier.

  • Hold to scroll

    Hold a button and move the mouse to scroll, with momentum. The MX Master 3 preset puts it on the right button, and a quick press still clicks.

  • Keys from any mouse

    Keys a mouse sends, like the number keys a Razer Naga's side buttons type, can become modifiers or shortcuts. A modifier is mapped below apps, so it holds in password fields too.

  • Pause from the menu bar

    See each device's state, apply settings again, pause everything or open the config file, all from one menu.

How it works

From download to done in three steps

  1. 1

    Install and allow two permissions

    Drag Hyperpoint into Applications and open it. Turn on Accessibility and Input Monitoring in System Settings. Until you do, the menu says Needs attention and nothing changes.

  2. 2

    Set up each device

    Every keyboard and mouse you plug in shows up under Devices. Start it from a preset for its model, copy another device's settings or start empty. Click Ignore and Hyperpoint leaves it alone.

  3. 3

    Press a button to add a rule

    Click Add Rule, press the button on your mouse and choose what it does. From then on, Hyperpoint keeps it in place through every sleep, wake and reconnect.

FAQ

Questions before you download

The short answers. The README on GitHub has the long ones.

Which Macs does Hyperpoint run on?

macOS 27 on Apple silicon. Download the DMG from the latest release, open it and drag Hyperpoint into Applications.

How big is it?

The download is 1.2 MB, and the app takes 3.3 MB once installed. It is one native Apple silicon binary with no bundled frameworks or runtime.

Does it work with mice other than the MX Master 3?

Yes. Every keyboard and mouse Hyperpoint sees shows up under Devices. Logitech mice that speak HID++ get their gesture and top buttons and the thumb wheel. Other mice get their plain buttons and any keys they send. Trackpads stay as macOS has them.

My MX Master 3 forgets its buttons after sleep. Does this fix it?

That is the problem Hyperpoint was built for. On every wake and reconnect it writes the full setup back to the mouse, and the menu shows when the mouse reconnected and that its settings were applied again.

Do I still need BetterMouse or Karabiner?

Not for what Hyperpoint covers: button rules and gestures, smooth scrolling, hold to scroll, the hyper key and remapping keys a mouse sends. Karabiner can also rewrite any key on any keyboard with complex rules. If you rely on those, keep it for them.

Why does it need Accessibility and Input Monitoring?

Accessibility lets the hyper key and smooth scrolling change keys and scrolls as they happen. Input Monitoring lets Hyperpoint set up the buttons on Logitech mice. Until both are on, the menu says Needs attention and nothing is applied.

Does Hyperpoint collect any data?

No. The app has no network code at all. Your settings live in one file on your Mac, and the log of what it did stays on your Mac too.

Where are my settings stored?

In ~/.config/hyperpoint/config.json. The settings window edits that file and nothing else, so you can edit it by hand too. A file with an error is rejected whole, with the path of the mistake, and the last good settings keep running.

What happens when I quit?

Hyperpoint clears the key mappings it made, so Caps Lock and your mouse keys go back to how macOS had them. To stop it for a while without quitting, choose Pause Hyperpoint from the menu.

How do I uninstall it?

Choose Quit Hyperpoint from the menu and drag the app to the Trash. To remove your settings as well, delete the ~/.config/hyperpoint folder.

macOS says the app cannot be opened. What now?

Version 0.1.0 came out before releases were notarized. Download 0.1.1 or later, or allow 0.1.0 under System Settings › Privacy & Security › Open Anyway.
